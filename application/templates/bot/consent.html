OAuth Server Consents

This lists all OAuth clients the Discord server has granted consent to. These consents grants the application using the OAuth client access to specific data about your Discord server based on the scopes/permissions granted to the OAuth client by the Discord server. Any member of the Discord server with admin perms will be able to revoke consent for any OAuth client at any time to prevent the application from accessing the server's data.
