Create a new steadfast event

A steadfast event shows the period for which the faction has a specific steadfast rotation set up. Each stat can have a steadfast set up between 0% and 20% for any period of time. For more information, see the documentation.

  • The steadfast for the strength stat must be between 0 and 20.
  • The steadfast for the defense stat must be between 0 and 20.
  • The steadfast for the speed stat must be between 0 and 20.
  • The steadfast for the dexterity stat must be between 0 and 20.
